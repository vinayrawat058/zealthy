# Zealthy Frontend (React + Vite)

See the root [README](../README.md) for full project docs, credentials, and setup.

## Quick start

Keep the backend on port **5000**, then:

```bash
cd frontend
npm install
npm run dev
```

App: http://127.0.0.1:5173
