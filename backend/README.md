# Zealthy Backend (Flask)

See the root [README](../README.md) for full project docs, credentials, and setup.

## Quick start

```bash
cd backend
python -m venv .venv

# Windows
.\.venv\Scripts\activate

# macOS/Linux
# source .venv/bin/activate

pip install -r requirements.txt
python run.py
```

API: http://127.0.0.1:5000
